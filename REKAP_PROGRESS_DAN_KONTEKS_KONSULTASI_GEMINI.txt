1. RINGKASAN PROYEK & ARSITEKTUR TEKNOLOGI
--------------------------------------------------------------------------------
Proyek ini adalah Monorepo Aplikasi Web "Portal Layanan Administrasi Kemahasiswaan"
menggunakan arsitektur Decoupled (Headless):

A. BACKEND (Folder: backend_api/)
   - Framework  : Laravel 12 / 13 (PHP 8.3+)
   - Database   : SQLite (database/database.sqlite)
   - Autentikasi: Laravel Sanctum
   - Output     : Murni RESTful API JSON standar
   - Port Server: http://localhost:8000 (dijalankan via: php artisan serve --port=8000)
   - Status Uji : 49 Unit & Feature Tests (Pest Framework) lulus 100% (220 assertions).

B. FRONTEND (Folder: weblayanan/)
   - Framework  : Nuxt 4 (Vue 3, Vite, SSR/SPA)
   - Bahasa     : TypeScript (nuxi typecheck: 0 error / 0 warning, Exit Code 0)
   - Desain & UI: Tailwind CSS v4, Reka UI / Shadcn Vue, Tabler Icons, TanStack Table v8
   - Port Server: http://localhost:3000 (dijalankan via: npm run dev)
   - Komunikasi : Fetch API asynchronous via useFetch & $fetch ke http://localhost:8000/api


--------------------------------------------------------------------------------
2. DAFTAR FITUR & ALUR KERJA SISTEM (USER WORKFLOW)
--------------------------------------------------------------------------------
1. Dashboard Utama (http://localhost:3000)
   - Menampilkan 4 kartu ringkasan status berkas: Layanan Tersedia, Sedang Diproses,
     Perlu Perbaikan, Selesai Terbit.
   - Tabel responsif TanStack Table v8 yang memuat daftar layanan dengan pagination,
     pencarian kolom, dan tombol langsung "Ajukan".

2. Katalog Seluruh Layanan (http://localhost:3000/layanan)
   - Menampilkan kartu lengkap 6 jenis layanan akademik resmi:
     1. Surat Keterangan Aktif Kuliah
     2. Surat Pengantar Penelitian & Riset
     3. Legalisir Ijazah & Transkrip / SKPI
     4. Surat Bebas Perpustakaan & Laboratorium
     5. Pengajuan Cuti Akademik
     6. Surat Rekomendasi Beasiswa & Prestasi
   - Live search filter berdasarkan nama surat, deskripsi, atau jenis berkas syarat.
   - Tombol "Detail Syarat" dan "Ajukan Sekarang".

3. Halaman Detail Layanan (http://localhost:3000/layanan/{id})
   - Menampilkan rincian dasar hukum dan penjelasan surat.
   - Ceklis dokumen persyaratan yang harus disiapkan.
   - Diagram alur 4 tahap proses verifikasi (Form -> Verifikasi BAAK -> Pengesahan -> Terbit).
   - Info SLA (1-3 hari kerja), biaya (Gratis Rp 0), dan tombol langsung "Ajukan Permohonan".

4. Formulir Pengajuan Surat (http://localhost:3000/pengajuan)
   - Dropdown opsi layanan yang otomatis menampilkan syarat resmi.
   - Input identitas: Nama Lengkap, NIM, Email, No. HP/WhatsApp, dan Catatan.
   - Input berkas persyaratan (dukungan Multipart Form-Data untuk PDF/JPG/PNG hingga 10MB).
   - Generate otomatis Nomor Pelacakan unik format REQ-YYYYMMDD-XXXX (contoh: REQ-20261020-8H2K).
   - Dialog sukses dilengkapi tombol salin kode dan pintasan langsung ke menu pelacakan.

5. Pelacakan Status Berkas Real-Time (http://localhost:3000/pengajuan/lacak)
   - Input nomor pelacakan atau auto-search via query parameter URL (?nomor=REQ-...).
   - Indikator status visual:
     * 'Pending'        : Menunggu antrean verifikasi.
     * 'Diproses'       : Berkas sedang ditinjau / ditandatangani pimpinan.
     * 'Perlu Perbaikan': Dokumen buram/salah + Catatan instruksi perbaikan dari petugas BAAK.
     * 'Disetujui'      : Surat resmi selesai dan siap diunduh/diambil di loket.
     * 'Ditolak'        : Permohonan tidak memenuhi kriteria akademik.

6. Riwayat Pengajuan (http://localhost:3000/pengajuan/riwayat)
   - Menampilkan tabel seluruh pengajuan mahasiswa.
   - Filter dropdown status dan live search nama/NIM/nomor registrasi.
   - Tombol "Lacak" langsung ke detail status pengajuan terkait.

7. Navigasi & Sidebar
   - Menu utama: Dashboard Layanan, Katalog Semua Layanan, Cek Status / Lacak, Riwayat.
   - Dokumen favorit: Akses cepat ke 3 layanan terpopuler + submenu "... Lainnya".
   - Header: Lonceng notifikasi dengan dropdown interaktif notifikasi surat disetujui/diproses.
   - Menu sekunder: Pengaturan Akun dan Pusat Bantuan & FAQ.


--------------------------------------------------------------------------------
3. DAFTAR ENDPOINT BACKEND API (routes/api.php)
--------------------------------------------------------------------------------
- GET  /api/ping                         : Health check koneksi backend
- GET  /api/layanan                      : Daftar seluruh layanan (support ?search=)
- GET  /api/layanan/{id}                 : Detail layanan berdasarkan ID atau Slug
- POST /api/pengajuan                    : Simpan permohonan baru & upload berkas fisik
- GET  /api/pengajuan/lacak/{nomor}      : Ambil status & catatan revisi berdasarkan nomor pelacakan
- GET  /api/pengajuan/riwayat            : Daftar seluruh pengajuan (support filter status, NIM, search)
- GET  /api/pengajuan/stats              : Agregasi metrik kartu dashboard
- PUT  /api/pengajuan/{id}/status        : Update status pengajuan & catatan revisi (untuk Petugas/Admin)

5. CATATAN HASIL UJI RASA PENGGUNA AWAM NON-IT ("ROLEPLAY BUDI")
--------------------------------------------------------------------------------
Ketika disimulasikan dari sudut pandang mahasiswa baru awam non-IT, ditemukan beberapa
potensi kebingungan (friction points) yang bisa dijadikan bahan diskusi perbaikan:

1. Ambigu Kotak Unggah Berkas Persyaratan:
   - Ada 3 syarat dokumen (KTM, UKT, KRS), tapi hanya ada 1 kotak dropzone umum.
   - Mahasiswa awam bingung apakah harus menggabungkan file jadi 1 PDF dulu atau bisa upload sekaligus.
   - Saran: Tambahkan petunjuk "Bisa pilih lebih dari 1 file sekaligus" atau sediakan slot upload per syarat.

2. Belum Ada Pop-Up Konfirmasi Sebelum Kirim:
   - Begitu tombol "Kirim Pengajuan Sekarang" diklik, form langsung terkirim tanpa step review.
   - Mahasiswa khawatir jika salah ketik 1 angka pada NIM atau nomor WhatsApp.
   - Saran: Tambahkan dialog ringkasan: "Periksa Kembali Data Anda [Batal] [Kirim Sekarang]".

3. Potensi Panik Jika Lupa Nomor Pelacakan (REQ-YYYYMMDD-XXXX):
   - Jika mahasiswa lupa mencatat kodenya, di halaman lacak belum ada tombol bantuan pencarian.
   - Saran: Beri link bantuan "Lupa nomor pelacakan? Cari berdasarkan Nama/NIM di menu Riwayat".

4. Status "Perlu Perbaikan" Belum Ada Tombol Upload Berkas Revisi:
   - Jika petugas BAAK meminta revisi (misal KTM buram), di halaman lacak belum ada form unggah ulang.
   - Mahasiswa terpaksa mengulang pengajuan baru dari awal.
   - Saran: Tambahkan tombol "Unggah Dokumen Perbaikan" langsung di halaman pelacakan.

5. Status "Disetujui" Belum Ada Info Pengambilan Fisik / Download Digital:
   - Mahasiswa bingung apakah surat digital bisa langsung diunduh atau harus datang ke loket BAAK.
   - Saran: Tambahkan tombol "Unduh Surat Digital" dan panduan loket kampus Ruang 102.

6. Label "Sesuaikan Kolom" pada Tabel Masih Format Database:
   - Dropdown kolom masih menampilkan nama variabel koding ("deskripsi", "persyaratan").
   - Saran: Ganti label teks menjadi lebih ramah ("Deskripsi Singkat", "Daftar Persyaratan").

7. Panel Khusus Admin / Petugas Kampus:
   - Backend API sudah mendukung penuh (PUT /api/pengajuan/{id}/status), namun antarmuka UI khusus
     Admin/Petugas BAAK di frontend (misal /admin) belum dibuat.
