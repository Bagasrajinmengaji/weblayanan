1. RINGKASAN PROYEK & ARSITEKTUR TEKNOLOGI
--------------------------------------------------------------------------------
Proyek ini adalah Monorepo Aplikasi Web "Portal Layanan Administrasi Kemahasiswaan"
menggunakan arsitektur Decoupled (Headless):

A. BACKEND (Folder: backend_api/)
   - Framework  : Laravel 12 / 13 (PHP 8.3+)
   - Database   : SQLite (database/database.sqlite)
   - Autentikasi: Laravel Sanctum (Token-based API Auth)
   - Fitur Auth : Dual-role (Admin BAAK & Mahasiswa), SSO Google OAuth 2.0
   - Port Server: http://localhost:8000 (dijalankan via: php artisan serve --port=8000)
   - Status Uji : 49 Unit & Feature Tests (Pest Framework) lulus 100% (220 assertions).

B. FRONTEND (Folder: weblayanan/)
   - Framework  : Nuxt 4 (Vue 3, Vite, SSR/SPA)
   - Bahasa     : TypeScript (Strict Type checking, 0 error / 0 warning)
   - Desain & UI: Tailwind CSS v4, Reka UI / Shadcn Vue, Tabler Icons, TanStack Table v8
   - Port Server: http://localhost:3000 (dijalankan via: npm run dev)
   - Komunikasi : Fetch API asynchronous via useFetch, useLazyFetch & $fetch ke http://localhost:8000/api

2. DAFTAR FITUR & ALUR KERJA SISTEM (USER & ADMIN WORKFLOW)
--------------------------------------------------------------------------------
1. Halaman Masuk Utama: Form Login Split 2 Kolom (http://localhost:3000/login)
   - Pintu masuk utama sistem (pengguna umum yang belum login otomatis diarahkan ke sini).
   - Sisi Kiri (Form Simple):
     * Logo Identitas Kampus: "PortalLayanan | BAAK" & Link Lacak Surat Cepat.

     * Pemisah "OR" dan input Username/Email & Password.

     * Bagian instruksi "Is this your first time here?" dan tombol "Create new account".
   - Sisi Kanan (Hero Banner Kampus):
     * Foto auditorium universitas dengan mahasiswa berjas almamater oranye (/campus-banner.jpg).
     * Deskripsi resmi layanan persuratan mandiri BAAK.
     * 4 Kartu keunggulan: Verifikasi Terukur (1-2 hari), Dokumen Resmi & Sah,
       Pelacakan Real-Time, dan Akses SSO Terpadu.
     * Jadwal loket operasional (Senin - Jumat 08.00 - 15.30 WIB).

2. Fitur Aksesibilitas Universal (Floating Widget Alt+A)
   - Tombol lingkaran biru di pojok kanan bawah dengan piktogram aksesibilitas universal.
   - Panel kustomisasi ramah pengguna:
     * Skala ukuran teks: Normal (100%), Besar (115%), Ekstra (130%).
     * Mode Kontras Tinggi: Meningkatkan kontras teks dan mempertegas garis elemen.
     * Garis Bawahi Tautan (Underline links): Memudahkan identifikasi hyperlink.
     * Font Ramah Baca: Jenis font sans-serif dengan spasi dan keterbacaan tinggi.
     * Kurangi Gerakan (Reduce motion): Mematikan animasi transisi.
     * Tombol reset preferensi default (tersimpan otomatis di localStorage).

3. Registrasi Akun Mahasiswa Baru (http://localhost:3000/register)
   - Menggunakan layout 2 kolom yang selaras dengan halaman login.
   - Formulir pendaftaran mandiri: Nama Lengkap, NIM, Email Mahasiswa, Password, dan Konfirmasi.
   - Tombol "Kembali ke Login" mengarahkan kembali ke /login.
   - Pilihan daftar instan menggunakan Google SSO.

4. Dashboard Layanan Mahasiswa (http://localhost:3000/)
   - Khusus akun Mahasiswa (terproteksi auth middleware).
   - Menampilkan kartu ringkasan status berkas dan panduan alur 3 langkah persuratan mandiri.
   - Tombol aksi cepat: Ajukan Surat Baru, Lacak Status, dan Muat Ulang Data.

5. Panel Admin BAAK (http://localhost:3000/admin)
   - Khusus akun role 'admin' (terproteksi admin middleware).
   - KPI Metrik Cards: Total Pengajuan, Pending Verifikasi, Sedang Diproses, Disetujui, Perlu Revisi.
   - Filter tabel permohonan masuk: Live search nama/NIM/nomor pelacakan dan filter jenis layanan.
   - Modal Dialog Verifikasi Berkas Petugas:
     * Tinjau data identitas pemohon dan unduh scan berkas persyaratan fisik.
     * Aksi status: "Diproses", "Perlu Perbaikan" (wajib isi catatan instruksi revisi),
       "Disetujui" (surat resmi siap terbit), atau "Ditolak".

6. Katalog Seluruh Layanan (http://localhost:3000/layanan)
   - Menampilkan 6 jenis layanan akademik resmi:
     1. Surat Keterangan Aktif Kuliah
     2. Surat Pengantar Penelitian & Riset
     3. Legalisir Ijazah & Transkrip / SKPI
     4. Surat Bebas Perpustakaan & Laboratorium
     5. Pengajuan Cuti Akademik
     6. Surat Rekomendasi Beasiswa & Prestasi
   - Live search filter dan link detail ke /layanan/{id}.

7. Formulir Pengajuan Surat Mahasiswa (http://localhost:3000/pengajuan)
   - Khusus mahasiswa (Admin yang membuka halaman ini otomatis dialihkan kembali ke /admin).
   - Input identitas dan upload scan berkas persyaratan online (dukungan multipart PDF/JPG/PNG).
   - Generate otomatis Nomor Pelacakan unik format REQ-YYYYMMDD-XXXX.

8. Pelacakan Status Berkas Real-Time (http://localhost:3000/pengajuan/lacak)
   - Dapat diakses langsung oleh publik/mahasiswa/admin tanpa perlu login.
   - Input nomor pelacakan unik atau auto-search via query parameter URL (?nomor=REQ-...).
   - Menampilkan progres status: Pending -> Diproses -> Perlu Perbaikan (dengan catatan) -> Disetujui.

9. Riwayat Pengajuan Mahasiswa (http://localhost:3000/pengajuan/riwayat)
   - Daftar riwayat pengajuan milik mahasiswa dengan filter status dan pencarian.

5. DAFTAR ENDPOINT BACKEND API (routes/api.php)
--------------------------------------------------------------------------------
A. Autentikasi & Akun:
   - POST /api/auth/login                : Login manual (Email/Username + Password)
   - POST /api/auth/google               : Login / Registrasi otomatis via Google SSO Token
   - POST /api/auth/register             : Registrasi akun mahasiswa baru manual
   - GET  /api/auth/me                   : Mengambil sesi profil user saat ini (Sanctum)
   - POST /api/auth/logout               : Hapus token sesi pengguna

B. Layanan & Pengajuan Berkas:
   - GET  /api/ping                      : Health check koneksi backend
   - GET  /api/layanan                   : Daftar seluruh layanan (support ?search=)
   - GET  /api/layanan/{id}              : Detail layanan berdasarkan ID atau Slug
   - POST /api/pengajuan                 : Simpan permohonan baru & upload berkas fisik
   - GET  /api/pengajuan/lacak/{nomor}   : Ambil status & catatan revisi berdasarkan nomor pelacakan
   - GET  /api/pengajuan/riwayat         : Daftar riwayat pengajuan (support filter status, NIM, search)
   - GET  /api/pengajuan/stats           : Agregasi metrik kartu dashboard (Pending, Selesai, dll)
   - PUT  /api/pengajuan/{id}/status     : Update status pengajuan & catatan revisi (Verifikasi Admin)
