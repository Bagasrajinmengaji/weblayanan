================================================================================
1. ARSITEKTUR & CARA KERJA PROJECT (DECOUPLED MONOREPO)
================================================================================

Aplikasi ini menggunakan pendekatan Decoupled Architecture (Headless), di mana
Backend dan Frontend terpisah secara logic namun berada dalam satu repository (Monorepo):

Folder Utama:
1. `backend_api/` : Bertindak sebagai penyedia data murni (RESTful API Server).
   - Berjalan di: http://localhost:8000 atau http://backend_api.test
   - Database: SQLite (`database/database.sqlite`)
   - Bertanggung jawab memvalidasi input, menyimpan berkas fisik, meng-generate
     nomor registrasi unik, mengelola status alur verifikasi berkas, dan menyajikan JSON.

2. `weblayanan/`  : Bertindak sebagai Single Page Application (SPA / SSR) berbasis Nuxt 3.
   - Berjalan di: http://localhost:3000
   - Mengambil (fetch) data secara asynchronous dari Backend menggunakan `$fetch` & `useFetch`.
   - Menampilkan UI modern berbasis Tailwind v4, komponen Shadcn, dan interaktivitas real-time.

--------------------------------------------------------------------------------
ALUR KERJA PENGGUNA (USER WORKFLOW):
--------------------------------------------------------------------------------
[1] DASHBOARD UTAMA (Nuxt: app/pages/index.vue)
    - Pengguna membuka http://localhost:3000.
    - Nuxt memanggil endpoint GET /api/layanan dan GET /api/pengajuan/stats.
    - Tampil 4 kartu ringkasan status berkas (Layanan Tersedia, Sedang Diproses,
      Perlu Perbaikan, Selesai Terbit) dan tabel daftar 6 layanan administrasi.

[2] PENGAJUAN SURAT BARU (Nuxt: app/pages/pengajuan/index.vue)
    - Mahasiswa mengklik tombol "Ajukan" pada tabel atau navigasi atas.
    - Sistem memuat dropdown opsi layanan dan menampilkan daftar persyaratan resmi.
    - Mahasiswa mengisi identitas: Nama, NIM, Email, No. HP, Catatan, dan mengunggah berkas PDF/JPG.
    - Form dikirim ke POST /api/pengajuan (dukungan Multipart Form-Data).
    - Backend Laravel:
      a. Memvalidasi seluruh input.
      b. Mengunggah file ke `storage/app/public/uploads/pengajuan`.
      c. Men-generate nomor pelacakan unik format `REQ-YYYYMMDD-XXXX` (misal: REQ-20261016-8H2K).
      d. Mengeset status awal menjadi 'Pending'.
      e. Mengembalikan HTTP 201 Created dengan objek pengajuan lengkap.
    - Frontend menampilkan dialog sukses dengan nomor pelacakan dan tombol salin/lacak.

[3] PELACAKAN STATUS REAL-TIME (Nuxt: app/pages/pengajuan/lacak.vue)
    - Mahasiswa memasukkan nomor pelacakan ke kolom pencarian (atau via link otomatis ?nomor=REQ-...).
    - Nuxt memanggil GET /api/pengajuan/lacak/{nomor_pelacakan}.
    - Sistem menampilkan status saat ini:
      * 'Pending'        : Berkas masuk dalam antrean.
      * 'Diproses'       : Berkas sedang diperiksa/ditandatangani pimpinan.
      * 'Perlu Perbaikan': Dokumen buram/salah + Catatan instruksi perbaikan dari petugas BAAK.
      * 'Disetujui'      : Surat resmi selesai dan siap diunduh/diambil di loket.
      * 'Ditolak'        : Permohonan tidak memenuhi kriteria akademik.

[4] RIWAYAT PENGAJUAN (Nuxt: app/pages/pengajuan/riwayat.vue)
    - Mahasiswa / Admin membuka menu "Riwayat Pengajuan".
    - Nuxt memanggil GET /api/pengajuan/riwayat.
    - Tampil tabel seluruh pengajuan lengkap dengan pencarian nama/NIM/nomor serta filter status.

[5] PROSES ADMIN / UPDATE STATUS
    - Pihak administrasi dapat memperbarui status dan catatan revisi melalui PUT /api/pengajuan/{id}/status.
    - Perubahan status langsung tercermin di dashboard metrik dan pelacakan mahasiswa.

Cara menjalankan server Backend (jika belum running):

TIPS POSTMAN:
- Tambahkan Header default untuk semua request:
  Key   : Accept
  Value : application/json

4. CARA IMPORT CEPAT KE POSTMAN MENGGUNAKAN CURL
================================================================================

Jika Anda ingin langsung mencoba tanpa mengetik manual di Postman:
1. Buka Postman.
2. Klik tombol "Import" (di pojok kiri atas).
3. Paste salah satu baris perintah cURL di bawah ini:

Contoh 1 (Cek Layanan):
curl -X GET http://localhost:8000/api/layanan -H "Accept: application/json"

Contoh 2 (Tambah Pengajuan):
curl -X POST http://localhost:8000/api/pengajuan \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d "{\"layanan_id\":1,\"nama_mahasiswa\":\"Budi Santoso\",\"nim\":\"2201011045\",\"email\":\"budi@student.ac.id\",\"no_hp\":\"081234567890\"}"

Contoh 3 (Lacak Pengajuan):
curl -X GET http://localhost:8000/api/pengajuan/lacak/REQ-20261016-1002 -H "Accept: application/json"

Contoh 4 (Update Status):
curl -X PUT http://localhost:8000/api/pengajuan/2/status \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d "{\"status\":\"Disetujui\",\"catatan_revisi\":\"Surat selesai ditandatangani. Silakan ambil di loket BAAK.\"}"
